# Ruleta

Ruleta personalizable de Guillermo García. HTML, CSS y JavaScript sin dependencias.

- Opciones editables, ordenación y mezcla aleatoria.
- Giro animado con selección uniforme mediante Web Crypto.
- Historial, tema claro/oscuro y guardado local.
- Eliminación opcional del ganador y duración configurable.
- Diseño adaptable y respeto a la preferencia de movimiento reducido.

Para usarla en local: `python3 -m http.server 8000` y abrir http://localhost:8000.

GitHub Pages publica la raíz de la rama `main`. No requiere compilación.
